# Gran Sol · Monta el Turno

Simulacro de plantilla y turnos de la Cervecería Gran Sol (Ríos Rosas 10, Madrid).
Crea trabajadores, reparte la semana de turnos y cuadra el coste de personal contra
el servicio y las ventas. Horario base tomado de La Castela (L-S, domingo cerrado).

- `index.html` — la webapp (autónoma). En breve, versión conectada a Supabase para
  sala compartida en vivo y escenarios guardados entre varias personas.

Diseñado con los agentes CEO, CFO y CHRO del proyecto Gran Sol.
